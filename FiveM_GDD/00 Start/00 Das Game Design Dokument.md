Hier werden die Features/Ressourcen für den FiveM Server beschrieben. Es dient als Game Design Dokument und beschreibt den aktuellen zustand der Features.

## Konzept
Dieser FiveM-Server soll eine Brücke zwischen GTA-Online und GTA-RP bilden. Es sollen grundsätzlich ähnliche Features wie in GTA-Online umgesetzt werden, jedoch mit deutlich heruntergedrehter Spielgeschwindigkeit. Dazu werden einige Features die Typisch für GTA-RP sind integriert.
